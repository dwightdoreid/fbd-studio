    FBD Studio — quick help
    
    
    
      
    Building a program
    
      
      
        
    • Drag blocks from the library on the left onto the canvas (or click a block to add it in the centre).
      • 
        
    • Connect an output (right side) to an input (left side) by dragging between the ports. Port colours show data types:
          BOOL
          INT
          DINT
          REAL
          TIME
      • 
        
    • Unconnected inputs use the constant shown next to them. Edit it in the properties panel. TIME values use IEC syntax, e.g. T#1s500ms.
      • 
        
    • The program runs as a PLC-style scan cycle. The small #n on each block is its execution order. A dashed wire closes a feedback loop and carries the value from the previous scan.
      • 
      
    
      
    Running it
    
      
      
        
    • Simulate runs the exact generated code on your PC. Click the switches on DI blocks; use the slider in the properties panel for AI blocks.
      • 
        
    • Upload builds with PlatformIO and flashes the board on the selected serial port. Monitor then shows live values from the board.
      • 
        
    • While online, you can change unconnected inputs (setpoints, timer presets) in the properties panel without re-uploading. Such changes are lost when the controller restarts, unless you press Save values: the controller then keeps them in its flash memory and uses them instead of the project's values after every restart. If you later change one of these inputs in the diagram and upload again, the new project value applies. Clear saved forgets all saved values. Copy to project takes the controller's current values into the diagram, so the project keeps what you tuned online. The simulator keeps saved values per project, so you can try this without hardware.
      • 
        
    • The Scope tab plots signals: click 📈 next to a value in the properties panel, or use “+ signal”. Trend plots the live values as they arrive; Capture records every scan on the board (or in the simulator), optionally from a trigger, for fast signals. Mouse wheel zooms, drag pans, double-click resets. Drag the top edge of the bottom panel to make it taller.
      • 
        
    • Export… gives you the generated PlatformIO project to continue in C++, or a Modelica package to test the program against a model of the machine in OpenModelica.
